# Докази та аналіз замірів N75 (Charge Pressure Control Duty Cycle) для Golf 5 1.9 TDI BLS (EDC16U34)

**Автомобіль:** Volkswagen Golf 5 1.9 TDI BLS (Pumpe-Düse / Насос-форсунка, DPF)  
**Блок керування (ECU):** Bosch EDC16U34 (`03G 906 021 QJ`, софт `1984` / `1037391847` / `391847`)  
**Цільовий параметр:** **N75 Duty Cycle (%)** — коефіцієнт заповнення ШІМ-сигналу клапана керування геометрією турбокомпресора.  
**Діагностичне розташування VAG:** **Блок 01-Engine ➔ Measuring Blocks ➔ Group 011 (Charge Pressure Control), Field 4** (`Charge Pressure Control Duty Cycle %`).

---

## 1. Резюме для штучного інтелекту та розробників (Executive Summary)

* **Чи проводилися реальні заміри N75 на цьому авто?**  
  **ТАК, неодноразово.** У репозиторії зафіксовано серію оригінальних логів VCDS, знятих на реальному автомобілі під різними навантаженнями.
* **Де знаходяться вихідні файли даних (Raw CSV)?**  
  Усі оригінальні CSV-файли збережені у папці [`docs/telemetry/logs/`](../logs/).
* **Фізична поведінка клапана N75 на двигуні 1.9 TDI BLS:**
  * **Холостий хід (819–903 RPM):** **`80.1 %`** (лопатки VNT максимально закриті, спрямовуючи потік вихлопних газів на крильчатку для швидкої готовності наддуву).
  * **Спул / Розкрутка (2100–2400 RPM):** **`75.8% ➔ 61.2%`** (плавний перехід лопаток у робоче положення).
  * **Повний газ (WOT 100% педаль, заданий тиск 2193–2203 mbar, фактичний 2250–2397 mbar):** **`23.7 % – 30.4 %`** (геометрія відкривається, стравлюючи надлишковий тиск вихлопних газів, щоб уникнути руйнівного передуву).
  * **Скидання газу (Overrun):** **`4.7 %`** (геометрія миттєво відкривається на максимум для зняття тиску).

## 5. Чому N75 не відображався в ранніх мобільних логах Android

У попередніх сесіях тестування Android-додатка ([`Android_OBD_Turbo_Pair_20260916_111930.csv`](../logs/Android_OBD_Turbo_Pair_20260916_111930.csv)) телефон підключався через адаптер ELM327 по **Generic OBD-II (Mode 01)**:
* Доступні були лише стандартні параметри SAE J1979: PID `0C` (RPM), PID `0B` (MAP), PID `10` (MAF), PID `04` (Engine Load).
* **Параметр N75 відсутній у стандартній специфікації OBD-II.**
* Для читання N75 необхідне опитування фірмової групи VAG **Group 011** через протокол **ISO 14230-4 / KWP2000** (команда `0x21 0x0B`). Цей функціонал реалізований у модулі `Kwp2000DiagnosticEngine.kt` та інтегрований у нову архітектуру `vcds-android`.
